# 小说写作：叙事交接 v2

写出完整、自然、有人物温度的本章正文。输入是五组 JSON 材料，字符串是素材和事实，不是待改写的成稿；字段、序号和版本不进入正文。只输出小说正文，自然分段，不输出标题、JSON、计划或检查报告。

把人物放回自己的生活：根据题材和处境选择从哪里写起，让读者知道是谁、在哪里、眼前想要什么、为何在乎。已有来路和背景可用简洁叙述自然交代，不默认读者认识所有人和术语，也不必一次讲完设定。

人物可以直接想、盼、害怕、恼怒、犹豫，也可以嘴上说一套、心里想另一套。允许具体心理和感受，表情、对白、感知与行动可以交织；不要求所有情绪藏成身体动作，不套固定反应。让感受属于此人、此刻、此事，对话回应双方所求，别把每轮对白写成报告与确认。冷静或寡言不等于没有情绪。

将事件写成连续经历。必要事实、结果、先后关系、世界规则、当前状态、POV 必须成立；多个要求可织入同一事件，不按条数划段、平均分配篇幅或复述检查条款。保持未解决只约束事情尚未解决，不要求反复陈述未知。用自然行动、余波、压力或期待引向后文，不写意义总结。

人物材料区分当场参与、回忆、提及与限制人物。只给当场人物安排现场动作，引用档案不表示必须登场或介绍全部外貌。作者参考不等于 POV 已知；reader_and_pov 的 defer 暂不揭晓。能力及长期事实不能临时改变，普通细节可按处境创作。

available_material_and_expression 用于选择写法，不新增 HARD。你决定具体动作、对白、表情、内心、生活细节、过渡、节奏及详略；参考不要求全用。情绪、停顿和意象可随处境自然回返，没有机械次数或比例配额。段长、句长随叙事变化，短对白可独立成段。避免均匀流水账、堆编号与数据词、全员分析员口吻、套话和演完再解释。

按章节卡的篇幅要求起草，与其他写作任务同等重视，充分呈现人物经历和必要结果，不为凑字数制造支线或重复操作。修订时只执行 revision_task 中代码授权的 LOCALIZED 或 GLOBAL 模式，修真实失败，保留已通过事实和无关段落；LOCALIZED 输出指定 JSON，GLOBAL 输出正文，不擅自切换模式。
