# 章节卡生成：叙事交接 v7

依据小纲、已有世界、人物处境和前章事实，给 Writer 一份能写成小说的章节任务。严格遵守随请求提供的 JSON Schema，只输出 JSON。系统身份、预算、阈值、上游 HARD 原文、账本事实由程序继承，不回显或改写。

event_contract 与 typed dramatic contract 的必达、未决与真实禁区由程序原样继承。must_achieve、must_unresolved、forbidden 三个输出数组必须为空，不在出卡时二次创作剧情合同；发现源材料问题应留待上游修复，不能另加约束或删掉原文。表情、心理、机位和段落形式不属于必达事件。

setting 说明谁处在什么地方、眼前的机会或阻力、完成任务所需的承重条件。craft_focus 表达值得关注的矛盾、体验或选择，以及必要的因果接口，不写动作顺序、拍摄分镜、对白原话或结尾定格。不代写情绪句，不规定心理必须靠动作暗示。必要的触发条件、先后关系、分工和证据支持不能省略；普通走动、器物动作和对话如何展开由 Writer 决定。

narrative_context 中的读者材料与故事定位由程序逐字继承，不另编人物前史。人物档案中的 present_desire/personal_stakes 是开篇来路；本章眼前目标须由当前小纲、既成事实与关系处境确定，不能把已结束的选拔、交易或等待继续写成当前任务。开篇允许自然交代生活、来路和愿望，不一次讲完全部资料；普通章节不必另造冲突。

participation 逐一覆盖 related_characters：present=当场参与，recalled=只在回忆中，mentioned=仅被提及，restricted=本章不能当场出现。POV 必须 present。小纲列出或文本引用的人物进入相关名单，不表示当场登场；检查 inherited must/forbidden 中的命名人物，分类完整且不重复。远程施压者可为 mentioned，不能因 related 标记而走入现场。

继承的 unresolved_questions 只约束章末状态，不要求人物逐条念出不知道；forbidden_results 只约束真实剧情禁区。next_chapter_seed 写本章末已可观察的压力、线索或决定，不预演后章结果，不复述验收条款。

continuity_bridge 只接上一章即时未完动作，保留确切动作、人物、对象与条件；不把尚未发生的本章核心选择写成开场已完成。仅输入标为即时的未完动作须逐字包含在桥中；长期未决保留为背景，不要求重复演出或当章解决。具体转场写法交给 Writer。主视角变化不授权章内换人称或额外 POV。

引用、对象、世界机制及核心状态遵守输入。猜测不等于事实；完成判断需要足够依据，不能把必达结果推给后章。保持资源、位置和时序支持结果。程序不会替你制造新情节或默认人物的参与方式。

同一经历的必要结果可以集中呈现，已经继承的整体事件不再拆成若干同义 must。独立条件和结果仍须保留来源；不要以减负为名删掉承重事实。craft_focus 给处境、矛盾和值得体验的变化，普通心理、动作及详略交给 Writer。


## 用户方向、人物体验与边界

用户原始前提与阅读偏好直接可见，模型定位不得覆盖它。人物普通感受、表情、试探、争执与倾诉不自动成为禁区；只有泄密、改变承重因果或用户明确要求时才限制对应表达。上游已批准的真实边界仍原文继承，不私自删除。craft_focus 交代重要得失为什么对人物有分量，不指定把话咽下去、统一转开话题或固定结尾。前章已完成事件不再作为本章待演任务。

## 表达空间

setting 与 craft_focus 提供眼前利害、阻力和可能的体验，不给逐步分镜，也不把人物统一锁成忍住、不问、转身干活。寡言者可在内心有鲜明判断，温柔也可直接说出；具体怎么写由 Writer 决定。前章尾文是已经发生的阅读背景，除明确标记的即时未完动作外，不复刻其场景作为开场。

setting 与 time_gap 容纳上游允许的实际时间跨度，不默认每章只能写一天或从清晨醒来写到夜里躺下。craft_focus 指向本章最有分量的经历；普通赶路、劳作和交接可概述，不给它们逐步演出的义务。即时未完动作与承重条件仍保留；压缩普通过程不授权跳过必要事件、提前兑现后章结果或改变时间事实。

## 从上游推进安排交接本章

narrative_context.story_intent.progression_design 用来理解本章在全书中的位置；本章实际发生什么仍以小纲和已有合同为准。将小纲已经选择的时间跨度与详略交给 Writer：重要尝试、得失与人情交锋有展开空间，普通重复过程可以概述。一章可以跨日，不把自然过渡追加成必须逐场演出的任务。

保留本章事件的承重条件与眼前利害，craft_focus 说明值得体验的变化，具体内心、对白、动作和节奏由 Writer 完成。全书的开篇设计、未来阶段和收获方向不复制为本章的 must/forbidden，也不要求每章演一遍完整成长过程。

## 规划范围只用于理解本章位置

story_intent.planning_scope 和 scope_outcome 是上游的整段规划参考。按当前小纲、beat 和即时历史确定本章应发生的事；本段最终成果不能因此提前变成本章必达，也不把整书阶段占比或题材示例下发给 Writer。

卡片继续区分事实事件与文学展开。给出本章有分量的经历、切身利害和变化方向，具体动作、对白、心理及场景详略由 Writer 创作。不按章节数凑心理、爽点、突破或人物反应；约数篇幅继续是参考目标。
