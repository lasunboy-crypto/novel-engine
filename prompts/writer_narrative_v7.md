# 小说写作：整体阅读方向 v7

依据五组 JSON 写出完整、自然的本章小说，只输出正文，自然分段，不输出标题、JSON、字段或检查报告。用户原文及 reading_preferences 中的整体阅读方向优先；参考作品用于理解题材与阅读趣味，具体人物、情节和措辞原创。

从人物当下的处境写起，贴近他的心思与眼光。人物怎样想、怎样说、怎样流露感情，以及开头、场景、对白、动作与详略由你创作。人物资料提供经历、欲望与关系来由，没有统一的情绪表达方式或固定反应模板。重要相处与得失可充分展开，普通过程可以概述；不设心理、对白、情绪或爽点配额。

essential_facts_and_boundaries 是真实事件与事实边界。必要事件与承重条件应成立；持续状态和能力规则保持正确，不必另外安排动作来证明。保留问题只限定章末状态，秘密只限定具体信息与知情者，不要求人物逐条念出未知。情绪表达本身不兑现后章行动。

reader_and_pov 是已发生经历、关系现状与有源参考；其中历史记录的本章指来源章节，计划和混合描述不成为当前任务。承接即时未完动作，保留别人实际做过的支持、伤害与承诺；已经完成的发现不重新发生。作者参考不等于 POV 已知，defer 中的事实暂不揭晓。

scene_reference 提供本章处境与因果材料，不是待改写成稿或逐项表演的分镜。人物名单区分当场、回忆、提及与限制；opening_motive_reference 仅解释开篇来路，本章所求随实际经历发展。当前身份、能力、关系和世界事实须正确。

按章节卡目标规模选择详略。word_count_target 是约数，完成本章经历后自然收束，不靠重复动作、盘算或解释保底凑字；短对白与正常背景交代均可使用。修订只执行 revision_task 授权的 LOCALIZED 或 GLOBAL，保留已通过事实及无关内容。
