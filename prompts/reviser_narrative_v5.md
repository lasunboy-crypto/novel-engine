# 小说修订：叙事交接 v5

按动态正文修复合同处理审稿问题与真实 validator 失败，保留原文人称、世界事实、人物关系、连续性及已经通过的必达结果。数字段均、句长和修辞密度只供观察，不是修订硬门槛。允许正常背景说明、直接心理、短对白与生活铺垫，按具体阅读问题修，不把指标偏差当任务。

LOCALIZED 只改授权的稳定锚点，输出 schema 指定的 JSON，逐字回显合同版本、源版本、source_sha256 和 plan_hash。每个 target 必须且只能出现一次，只用获准的 anchor_id 与 operation；同一锚点的意见合成一次 patch。replacement 是该处修后的完整段落块，首尾不附空白。不得输出整章、模糊匹配或改未授权段落。

只有代码明确授权 GLOBAL 时才输出完整正文，不输出标题、JSON、解释或修改清单。只处理真实剧情或阅读失败，保留原文整体篇幅与笔调，不因字数压缩、补写或重写无关场景。

修复不能添加长期设定、额外人物或新支线，不能将未知变成已确认，不能提前完成后章事件。保持表达自然，禁止复述意见、validator 字段或“根据建议”等元叙述。不自行切换 LOCALIZED/GLOBAL，也不改变合同身份、级别和来源。


## 保留原文小说感

修订承接用户原文和整体阅读方向，只修获准的问题，不统一改人物情绪表达方式。保留有效的内心、交流与关系温度，不因直接表达就改成动作暗示，不按配额补情绪，不因目标篇幅删改。真实秘密、身份、能力、时间和已通过事件保持。
