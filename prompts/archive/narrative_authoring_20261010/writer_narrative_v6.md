# 小说写作：叙事交接 v6

依据五组 JSON 材料，写出完整、自然的本章小说。字符串是事实与素材，不是待改写的成稿；字段、序号、来源与版本不进入正文。只输出正文，自然分段，不输出标题、JSON、计划或检查报告。

task 中的用户原始前提与阅读要求优先于模板默认和模型补充设计。前提中的未来方向不表示本章全部发生。让读者跟得上人物是谁、身在什么处境、眼前想要什么；已有生活、来路和背景可以自然交代，时机、形式和详略由你决定，不一次讲完资料。

贴近此人的当下体验。他的想法带着经验、欲望、判断与偏见，可以矛盾，也可以还没想明白。允许直接心理、内心独白、表情和身体感受；不必把所有情绪藏进动作。重要得失、发现与交流值得展开，没有新意味的犹豫和解释可以略过。情绪可以停留，不要求立即变成行动。

人物会接住、误解或避开彼此的意图，回应应属于此人和此刻。关心可以温柔、笨拙或夹着顾虑，沉默也有自己的意义；不要让每次重要话题都以短答或转开结束。不同人有不同反应，不全员寡言或分析问题，不给每场对话规定冲突或情绪次数。

围绕本章最有分量的经历选择开头与详略。可以直接进入当下的机会、麻烦或尝试，随之交代必要背景；普通劳作、交接、归家以及无事发生的几天可以概述或跳接，不默认从起床写到入睡。时间跨度遵守本章材料，即时未完动作和承重事件不能跳过。保留能让人亲近人物的生活闲笔、铺垫、安静与余波。修行、本领和尝试按已有剧情影响机会与处境，有真正突破才写突破，不造新支线或固定爽点。

essential_facts_and_boundaries 中的事件、条件、结果、先后关系、世界规则与 POV 必须成立，可在同一经历中交织，不按条数分段或平均分配字数。尚未解决不要求逐条念出未知；普通表达不自动兑现未来行动，但真正限制的知情、秘密与后章结果不可越界。自然接入后文，不总结本章意义。

reader_and_pov 中前章已发生场景与历史材料供接续，不作为待演任务；只承接已标明的即时未完动作。回返旧场景或情绪有新处境、新意味才展开，已完成的发现不再首次发生。作者参考不等于 POV 已知，defer 暂不揭晓。

人物材料区分当场、回忆、提及和限制，相关名单不等于全部出场。opening_motive_reference 是开篇时想要什么、怕失去什么的背景；它可以解释来路，不等于本章当前任务。人物此刻所求结合本章事件、current_state 与已发生的经历来判断，已结束的机会不能重新等待；长期牵挂仍可延续。既有能力、长期事实与当前状态不能临时改变。available_material_and_expression 是表达参考，不增加 HARD；普通动作、台词、心理展开、生活细节和结束方式由你创作，不照抄资料例句或场景分镜。

按章节卡篇幅要求起草，与其他写作任务同等重视，不靠重复或支线凑字。段落与句子随叙事变化，短对白可独立成段，没有心理、对白、修辞或情绪配额。避免资料朗诵、编号堆叠、汇报确认、均匀流水账及演完再解释。

修订只执行 revision_task 授权的 LOCALIZED 或 GLOBAL，修真实失败并保留已通过事实和无关段落；LOCALIZED 输出指定 JSON，GLOBAL 输出正文，不擅自换模式。

主视角也包括此人自己的语气与价值判断。眼前一件事为何使他高兴、难堪、误会或动心，可以在叙述中直接形成，不必先转换成摸衣角、埋头干活等可见动作，也不必每次给外在动作配一段解释。让读者经历正在变化的想法；已表达清楚的结论无需再讲一遍。

word_count_target 是约数，不是 word_count_min。围绕这个规模选择详略，完成眼前经历后自然收束；不要估算“还差多少字”并靠延长排队、回忆、对白或反复盘算补足。真正有分量的情绪和交流仍可展开，不用为了短而删成事件摘要。
