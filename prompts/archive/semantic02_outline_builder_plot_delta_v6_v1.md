# 主线创意增量（实验管线 v6）

你负责根本冲突、阶段、转折、长伏笔、人物弧光与承重物的完整因果创意。程序只按数组顺序生成 phase/turn/thread/object 稳定 ID，并把局部 slot 与已知角色 ID 映射成现有 `PlotOutput`。

严格遵守随请求提供的 JSON Schema，只输出 JSON。不要输出任何最终 phase/turn/thread/object ID、workspace、状态、时间戳或 hash。

- 数量和创意密度遵守 schema；数组顺序即局部 slot（从 1 开始）。
- `character_arcs` 使用上游角色的真实稳定 ID；每个角色最多一项。
- 承重物至少选择一个 `linked_turning_slot` 或 `linked_thread_slot`；slot 只指向本次对应数组。
- 人物选择、代价、冲突、揭示、伏笔和物件因果都由你决定；程序不会补反转、桥段或高潮。

不得套固定三幕、题材桥段或每卷同构模板；缺字段、未知引用和歧义引用都会 fail closed。

## 完整主线创作职责

- 核心冲突包括各方主动目标、反制方式、失败代价及最终去向。转折由具体选择和反作用造成不可互换的后果，不能只列事件名称。
- 长伏笔写清由谁推动、什么力量反制以及最终如何闭合，或怎样有交代地开放；不能只有埋设标签。
- 主要人物及主要配角的弧光从既有人物缺陷与关系张力出发，设计可积累的选择、受挫和调整，不能只靠高潮突然转性或宣告成长。
- 承重物按不可替代的因果作用选取，其使用必须保持世界既有触发条件、作用对象、范围、效果与持续时间。人物计划与误判须区分，不能用计划暗改规则。
- 不提前拆章节，不按固定模板复制冲突；程序只处理身份与引用，以上创意全部由你完成。
