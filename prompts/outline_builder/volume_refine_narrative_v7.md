# 单卷长度感知重排增量（实验管线 v7）

输入卷的标题、概要、上游引用、arc/beat 身份与全部剧情文本已经冻结。你只在确有戏剧节拍重排需要时，返回新的 `chapter_count`、`tension_curve`、每个既有 arc 的范围和每个既有 beat 的范围。程序把这些变化机械应用到原卷，其余字段逐字复制。

严格遵守随请求提供的 JSON Schema，只输出 JSON。不要回显 volume/arc/beat ID、标题、概要、must/forbidden、dramatic contract、上游引用或模板名。

- `arcs` 与每个 `beats` 的数组顺序、数量必须与输入完全一致，禁止增删或换位。
- 范围必须连续、无重叠并覆盖新章数；张力长度必须精确等于新章数，元素只能是 1–10 整数。
- 不需要重排时也必须返回与原范围完全相同的显式 no-op delta；程序不会替你改戏剧节奏。

缺项、错序、数量变化或来源漂移都会 fail closed，不会回退到完整对象重写。

## 长度与戏剧判断

校准只描述观测到的长度，不证明演出充分。先判断同一事件是否被切得过薄，或多个吃重过程是否挤在一章。依据承重选择及其因果过程重排范围，避免把“增加章数”当成默认答案；不以 must 数量乘固定字数。若冻结的剧情材料本身缺失，重排不能冒充补全，保持材料原文并留下可复查结果，不自行编造新剧情。


## 只重排真实经历的分量

读取scope_experience、本段成果与既有phase_development。进入条件和进入后的经历不能被视为同一件事；依已冻结的尝试、得失、运用与后果分配空间。普通准备、路途、等待与重复修习继续概述，不因日数长就扩成逐日确认。静戏有真正的关系或选择分量时仍可展开。

只能改变现有范围和章数，剧情、顺序、身份、事实与戏剧合同原文保持；重排不能补全上游缺少的主要经历，也不能替Writer写分镜。参考字数不是下限，不以must条数或高张力直接换算篇幅；多个不同因果阶段确有分量才支持拆章，不为填字扩章。
